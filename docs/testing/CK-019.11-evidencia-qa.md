## Cobertura del flujo integrado

- Un cliente autenticado puede crear una reseña para su reserva completada.
- Se normaliza el comentario y se puede editar rating/comentario.
- El documento público no contiene `clientId`.
- La unicidad por `reservationId` se mantiene al intentar crear una duplicada.
- Una reserva pendiente no se puede reseñar y las reglas Firestore deniegan la escritura.
- Otro cliente no supera la validación de propietario.
- Las reseñas son legibles públicamente y no se pueden borrar.
